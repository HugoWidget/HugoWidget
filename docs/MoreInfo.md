## 深度参与

由于我们已经完全停止开发这些项目，如果有任何想法，可通过以下方式参与开发：

1. fork 组织仓库并 Pull Request

> 如果项目已经 Archive，可通过组织邮箱与我们联系以暂时解除归档状态

2. 加入社群

   通过组织邮箱获取加入方式
   
3. 加入组织

   向组织邮箱提交申请，内容包含：

   - GitHub 用户名
   - 是否在读/就读年级（可选）
   - 想要参与的项目
   - 其他想要补充的内容

以上方式长期有效，我们不能保证及时的回复，敬请谅解。
